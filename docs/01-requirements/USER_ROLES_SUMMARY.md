# EV Mobility Platform — User Roles Summary

| Role | Main Purpose |
|---|---|
| 🚗 EV Driver | Plan, charge, park and complete journeys |
| ⚡ Charging Operator | Manage charging infrastructure |
| 🅿️ Parking Operator | Manage parking and IoT bays |
| 🛡️ Admin | Manage the complete platform |
| 🚕 Fleet Manager | Future fleet optimization |

---

## Driver

**Main goal:**

> Plan my EV journey and reserve charging + parking.

---

## Charging Operator

**Main goal:**

> Improve charger utilization and monitor charging operations.

---

## Parking Operator

**Main goal:**

> Manage parking availability, occupancy and IoT access.

---

## Admin

**Main goal:**

> Control and monitor the platform.

---

## Future Fleet Manager

**Main goal:**

> Optimize multiple EVs and charging operations.

---

### MVP Roles

P0:

- EV Driver
- Charging Operator
- Parking Operator
- Admin

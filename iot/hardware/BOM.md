# Prototype Bill of Materials

Indicative low-voltage demo components:

- NodeMCU ESP8266 or ESP32 development board
- PZEM-004T V3 module for a supervised demonstration setup only
- DS18B20 temperature sensor
- status LEDs, resistors, and optional buzzer/OLED
- low-voltage demonstration load and isolated power supply
- occupancy sensor and micro-servo for the parking model

This is not a production charger design. Do not connect GPIO, breadboards, or exposed prototype circuits directly to mains or EV high-voltage systems. A qualified supervisor must approve any powered demonstration.

- Product/demo owner: scope, acceptance criteria, judge narrative, and data-honesty review.
- Web owner: driver/operator/admin experience, accessibility, API-only data access, and state management.
- API owner: HTTP contracts, authorization, transactions, orchestration, and compatibility.
- Intelligence owner: pure algorithms, explainability, tests, and estimation limitations.
- Data owner: Prisma schema, migrations, seed integrity, retention, and backups.
- IoT owner: low-voltage hardware safety, firmware, MQTT protocol, and simulator parity.
- Quality/operations owner: CI, E2E, security checks, demo runbooks, and recovery.

One person may hold multiple roles, but every release task needs a named reviewer outside its primary owner when possible.
